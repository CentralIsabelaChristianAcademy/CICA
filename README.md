# Central Isabela Christian Academy Website

A responsive one-page website created from the CICA source materials supplied for the project.

## Run locally

Open `index.html` in any modern browser. No build step, package manager, or internet connection is required.

For best local testing, you can also serve the folder with any static server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Included features

- Responsive desktop/mobile navigation
- Two-image hero slideshow
- Animated institutional statistics
- Interactive Philosophy / Vision / Mission / Goals tabs
- Draggable “Then / Now” campus photo comparison
- Scroll-reveal animation
- Historical milestone timeline
- Responsive Core Values cards
- Reduced-motion accessibility support
- Keyboard-accessible tabs and skip link
- No external libraries or third-party assets

## Project files

- `index.html` — site structure/content
- `styles.css` — visual design and responsive layout
- `script.js` — interactions
- `assets/images/` — supplied CICA imagery (optimized logo plus campus photos)
- `source-materials/` — supplied source text files

## Source note

Institutional wording and historical content are based on the supplied `PVMGO.txt` and `CICA-History.txt` files. The site intentionally does not add unsupported contact, enrollment, program, tuition, faculty, or social-media details.
